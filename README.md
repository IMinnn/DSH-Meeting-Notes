# DSH Meeting Notes · 会议记录

[![version](https://img.shields.io/badge/version-0.2.4-blue)](./package.json)
[![license](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)
[![platform](https://img.shields.io/badge/platform-DeepSeek%20Harness-7c3aed.svg)](https://github.com/IMinnn/DSH-Meeting-Notes)

> 「一键开录 + 实录弹窗」的 DeepSeek Harness 会议记录插件：点一下开始，说话就出字，结束自动总结。转写与发言人识别**全程在本机完成，录音不出这台电脑**。

基于开源插件 [dsh-meeting-room](https://github.com/kekydream/dsh-meeting-room)（MIT）精简重写。

## ✨ 功能特性

- 🎙️ **一键开录 + 实录弹窗**：居中大弹窗，转写实时上屏，边说边出字
- 🔊 **麦克风 + 系统声音同时录**：电脑里播放的声音直接内录（不采集屏幕画面），设计上支持耳机播放
- 💻 **全程本机识别**：录音 → 本机转写 → 实时实录，无云端依赖
- ⚡ **实时出字与后台整理分离**：识别采用约 6 秒短窗口，不随段落增长；发言人识别、纠错、数字规整异步回填，不阻塞下一段实时文字
- 🗣️ **按发言人分段**：自动区分说话人，换人立即分段；点名称改成真实姓名后，实录、纪要与导出全部同步替换；声纹入库后下次主动建议名字
- 📚 **内置词库 + 会议术语**：内置 16 个行业共 705 个常用词作纠错参考，按需勾选；支持本场术语（`错词=正确词`）
- 🔤 **语言纠错**：整句被误转成日文/韩文等时自动还原；确属外语发言则保留
- 📝 **会后自动总结**：结束录音即自动生成 AI 纪要、要点与待办，保存到专属会话
- 🎧 **右侧详情**：录音播放器（拖动进度、倍速、点击转写定位）+ 转写 / AI纪要 / 笔记 / 要点与工作安排页签
- 📤 **导出与历史**：按内容与格式导出（多项自动打 zip）、生成 Markdown / Word 纪要；会议工程包可导出/导入
- 🤖 **Agent 工具**：6 个 `meeting_*` 工具，代理可直接读实录、记要点、存纪要、查历史

## 📦 安装

### 环境要求

| 依赖 | 说明 |
| --- | --- |
| DeepSeek Harness | 已安装并可登录的宿主应用 |
| 操作系统 | macOS 14.2+ 或 Windows 10/11（系统声音内录）；仅麦克风录音无系统版本要求 |
| 识别模型 | 本地 SenseVoice 模型（首次在 **设置 → 会议记录 → 模型** 中下载或导入） |

### 安装步骤

```bash
git clone https://github.com/IMinnn/DSH-Meeting-Notes.git
```

1. 打开 DeepSeek Harness 的 **Plugins（插件）** 页，选择 **Add plugin**，指向克隆出的 `DSH-Meeting-Notes/dsh-meeting-notes` 目录；也可以直接在会话里让 Agent 用 `install_bundle` 安装该目录的绝对路径。
2. 安装后重启一次 Harness。
3. 输入框下方出现「🎤 会议记录」按钮即安装成功。

## 🚀 快速上手

### 开始一场记录

| 入口 | 操作 |
| --- | --- |
| 输入框工具行 | 点「🎤 会议记录」按钮打开弹窗，再点「开始记录」；录制中按钮显示红点与计时 |
| 斜杠命令 | 输入 `/meeting` 回车，打开窗口并开始 / 继续录音 |
| 左侧栏 | 点「会议记录」面板行，弹出记录窗口 |

弹窗内：顶部是状态与会议名称（可直接修改）；工具条「开始 / 暂停 / 结束」；左侧实录实时上屏，右侧笔记面板（纯文本，自动保存，并作为独立输入参与 AI 总结），中间分隔条可收起/展开。

### 结束与自动总结

1. 点「结束」，录音直接落盘并进入总结；误触可点「继续记录」一键续录。
2. 在 **设置 → 会议记录 → 会后工作区** 配置工作区（默认 `~/DSH/会议纪要`）。结束后宿主立即创建专属会话并显示会议卡片；总结在后台完成（长会议可能需要几分钟）。
3. 点卡片打开右侧详情：上方播放录音，下方 **转写 / AI纪要 / 笔记 / 要点与工作安排**；纪要和笔记可编辑保存，转写支持查找与点击定位。
4. 点「导出」选择内容（原文 / 会议总结 / 会议纪要 / 音频）与格式（txt / md / docx），多项自动打包 zip。总结失败时卡片上可一键重试。

## ⚙️ 设置与历史会议

- 所有配置在 **DSH 设置 → 会议记录**：会后工作区、模型（本地识别模型 + 后台总结模型）、发言人识别、实录选项、会议术语，保存即生效。
- 历史会议从录音弹窗头部进入，详情面板与会议卡片一致（播放、查找、编辑、导出）；每条记录可删除，删除后该记录的全部本机内容不可恢复。
- 重新打开弹窗总是新的一场会议；上一场从历史里查看，只有录音还在进行时才回到原面板。

## 🤖 Agent 工具

| 工具 | 用途 |
| --- | --- |
| `meeting_read` | 读取会议实录（时间轴 + 发言人 + 术语表） |
| `meeting_write` | 写入要点、决策与任务安排 |
| `meeting_revise` | 二次纠错实录中的识别错误 |
| `meeting_save_document` | 将总结 / 纪要存入会议记录 |
| `meeting_query` | 按日期或人员查询历史会议 |
| `meeting_session` | 创建会议、请求开始录音、查看录音状态 |

## 🔐 隐私与权限

- **录音不出本机**：转写与发言人识别全程本地完成，原始录音只在本地处理。
- **自动总结**会把实录和笔记发送给设置中配置的大模型通道；不配置则不外发。
- **权限**：麦克风需系统授权；系统声音内录在 macOS 需「系统音频录制」授权（与麦克风授权不同），Windows 无需屏幕录制权限与虚拟声卡（首次使用自动编译内录助手，约一分钟）。
- 原生内录不可用（如缺少编译工具）时，可安装一次 [BlackHole](https://github.com/ExistentialAudio/BlackHole)（`brew install blackhole-2ch`）改用多输出方案，插件自动切换并在结束时恢复。

## 📁 项目结构

