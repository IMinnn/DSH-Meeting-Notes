# 会议记录（dsh-meeting-notes）

DeepSeek Harness 会议记录插件：「**一键开录 + 实录弹窗**」——点一下开始，
说话就出字，结束自动总结。转写与发言人识别**全程在本机完成，录音不出这台电脑**。

## 亮点功能

- **一键开录 + 实录弹窗**：居中大弹窗，转写实时上屏，边说边出字。
- **麦克风 + 系统声音同时录**：电脑里播放的声音直接内录（不采集屏幕画面），
  设计上支持耳机播放；麦克风与系统音频需分别授权。
- **全程本机识别**：录音 → 本机转写 → 实时实录，无云端依赖。
- **实时出字与后台整理分离**：语音识别采用最长约 6 秒的短窗口，不随显示段落增长；
  定稿复用服务端校验的识别结果，不再重复争用识别器。发言人识别、段落合并、
  数字规整与纠错异步回填；后台积压时延后至会后补齐，不阻塞下一段实时文字。
- **按发言人分段**：自动区分说话人（发言人1、发言人2…），换人说话立即分段；
  点名称即可改成真实姓名，实录、纪要与导出全部同步替换。命名入库后，
  下次开到同一个声音会主动建议名字（只建议，改名由人确认）。
- **内置常用词与会议术语**：内置 16 个行业共 705 个常用词作纠错参考（词条随
  插件版本维护），设置里按需勾选，展开浏览时词库区域固定高度、面板内上下滚动；
  也可为本场会议填写术语（支持 `错词=正确词`）。
- **语言纠错（中文为主、英文为辅）**：识别器偶尔会把整句转成日文、韩文等
  其他文字，纠错默认这是转错语言，结合上下文还原成本来要说的话；确认
  真的是外语发言才保留原样。这类句子走快车道：不等凑批，定稿后立即在
  后台还原，转写与录制全程不被阻塞。
- **会后自动总结**：结束录音即自动生成 AI 纪要、要点与待办，保存到专属会话，
  无需手动新建对话。
- **右侧详情**：点击会议卡片，查看转写 / AI纪要 / 笔记 / 要点与工作安排；
  上方播放原始录音，支持拖动进度、倍速、点击转写定位。
- **导出与历史**：按内容与格式导出（多项自动打 zip）、生成 Markdown / Word 纪要；
  历史会议随时查看，会议工程包可导出/导入。
- **Agent 工具**：`meeting_read` / `meeting_write` / `meeting_revise` /
  `meeting_save_document` / `meeting_query` / `meeting_session`，
  代理可以直接读实录、记要点、存纪要、查历史会议。
- **设置集成**：模型、发言人、实录选项、会议术语统一在
  **DSH 设置 → 会议记录**，录音弹窗只管录音。

## 使用说明

### 开始一场记录

三个入口任选其一：

1. **输入框工具行的「🎤 会议记录」按钮**：打开记录弹窗，点「开始记录」开录；
   录制中按钮显示红点与计时。
2. **斜杠命令 `/meeting`**：输入框输入 `/meeting` 回车，打开窗口并开始/继续录音。
3. **左侧栏面板行「会议记录」**：点击弹出记录窗口。

弹窗内：顶部是状态与会议名称（可直接修改）；工具条上「开始 / 暂停 / 结束」，
右侧显示记录时长；左侧实录实时上屏，右侧是**笔记面板**（纯文本，自动保存，
并作为独立输入参与 AI 总结），中间的分隔条可收起/展开笔记。

### 权限

- **麦克风**：需要系统「麦克风」授权。
- **系统声音（内录）**：macOS 14.2+ 使用系统内录，需「系统音频录制」授权
  （与麦克风授权不同，不能互相代替）；Windows 10/11 内录无需屏幕录制权限，
  也不需要虚拟声卡，首次使用会自动编译内录助手，约需一分钟，麦克风不必等待。
- 宿主原生内录不可用（如缺少命令行编译工具）时，可装一次
  BlackHole（`brew install blackhole-2ch`）改用多输出方案，插件自动切换并在结束时恢复。

### 结束与自动总结

1. 点「结束」，录音直接落盘并进入总结；误触可点「继续记录」一键续录。
2. 先在 **设置 → 会议记录 → 会后工作区** 配置工作区（默认 `~/DSH/会议纪要`）。
   结束后宿主立即创建专属会话并显示会议卡片；总结在后台完成（长会议可能需要
   几分钟），聊天区只显示简短状态与卡片，完成后自动补齐。
3. 点击卡片打开右侧详情：上方录音播放器，下方 **转写 / AI纪要 / 笔记 /
   要点与工作安排** 页签；纪要和笔记可编辑保存，转写支持查找与点击定位。
4. 点「导出」选择内容（原文 / 会议总结 / 会议纪要 / 音频）与格式
   （txt / md / docx），多项自动打包为一个 zip。
5. 总结失败时卡片上可一键重试。自动总结会把实录和笔记发送给配置的大模型通道；
   原始录音始终只在本机处理。
6. 笔记参与 AI 纪要和「要点与工作安排」的整理；没有转写、只有笔记也可生成。
   长会议分段与合并均携带普通长度笔记原文核对遗漏；超长笔记独立分段整理，不作为口语转写。
   会后编辑笔记仅保存原文，不会自动改写已生成纪要。

### 设置与历史会议

- 所有配置在 **DSH 设置 → 会议记录**：会后工作区、模型（本地识别模型 +
  后台总结模型下拉选择）、发言人识别、实录选项、会议术语，保存即生效。
- 历史会议从录音弹窗头部进入，点击任意记录打开与会议卡片相同的详情面板
  （播放、查找、编辑、导出一致）；每条记录带删除按钮，确认后删除该记录的
  全部本机保存内容，不可恢复。
- 重新打开弹窗总是新的一场会议；上一场从头部的历史里查看，只有录音还在进行时
  才会回到原面板。
